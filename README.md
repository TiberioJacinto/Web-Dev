# Web-Dev

Repositório com os meus projetos de desenvolvimento web: páginas e landing pages feitas com HTML5 e CSS3, pensadas para negócios locais e com foco em design limpo, responsivo e fácil de manter.

## Projetos


| [`lavandaria/`](./lavandaria) | Landing page da **Berito MultiServices**, uma lavandaria. Inclui navegação, secção principal (hero), quem somos, serviços, porquê escolher a lavandaria, chamada para ação com contacto por WhatsApp e rodapé. 


[`sorveteria/`](./sorveteria) | Projeto de pagina simples para uma sorveteria. 



[`sun/`](./sun) |  Landing page da sun(nome ficticio), empresa de tecnologia.

## Tecnologias

- HTML5 semântico
- CSS3 (variáveis CSS, Flexbox, Grid, media queries)
- Design responsivo (computador, tablet e telemóvel)
- Google Fonts

## Estrutura de um projeto

Cada pasta segue, em geral, a mesma organização:

```
projeto/
├── index.html
├── style/
│   └── style.css
└── images/
```

## Como ver os projetos

Não é preciso instalar nada.

1. Clone o repositório:
   ```bash
   git clone https://github.com/TiberioJacinto/Web-Dev.git
   ```
2. Abra a pasta do projeto que quer ver, por exemplo `lavandaria/`.
3. Abra o ficheiro `index.html` no navegador.
